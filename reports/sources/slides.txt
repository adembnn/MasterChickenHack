API Access to the End Points & Query Budget

- Each query sends a prompt to one endpoint and returns
    generated text only.

- Each team may collect up to 100 responses per endpoint
    for the whole competition. A request for several responses
    uses one query per response.

- At most 256 generated tokens per response, and at most
    1,024 input tokens per prompt.

- At most 4 requests at a time per team.
- Sampling settings such as `temperature` and `seed` are

    ignored, and system messages are rejected.
- Invalid requests are rejected and not counted against your

    budget.

              Evaluation Metric

         Final score = forget score × retain score

Gate: under 70% held-out accuracy means both scores are 0

Models:

   orig: given model, trained on all data
   gold: retrained without the forget images (average of
   several models). This is the target.
   sub: your submission

                                                                                                                                                    44
               Evaluation Metric

   forget_score = mean_std_score × prediction_score

Loss-distribution score: an_std_score = 1 -  sub/rig, 0,1
d = | mean loss| + | std loss| vs gold
Prediction score: 1 - clip(KL(goldsub) / KL(goldorig), 0, 1)
Per image, against the gold average (softmax, T = 2)
Loss-distribution score checks the loss on forget images at the group level.
Gold has a specific average loss and spread.
Prediction score checks each image on its own. It makes sure the full output
distribution matches gold, not just the loss number

                                                                                                                                                       45
               Evaluation Metric

    retain_score = retain_accuracy_score × retain_kl_similarity

Accuracy score: clip(acc_sub(control) / acc_orig(control), 0, 1)
Measured on the held-out control set. Score is 1 if accuracy matches or
beats orig.
KL Similarity: 1 / (1 + mean KL(origsub))
Per image, against the orig distribution. Score is 1 if predictions match
orig exactly.
Accuracy score checks that the model still gets the right answers on data it
should keep
KL similarity checks that the outputs did not drift. Accuracy can stay flat
while confidence and class probabilities change a lot

               Evaluation Metric

Dataset
The dataset is a custom 100-class image classification dataset.

· model.pt: the provided pretrained model, as a weights-only PyTorch state
· forget_images.npz: the 3,500 images that make up the forget set. Labels

   are not included.
· task_template.py: a helper script for loading the provided model

   checkpoint and forget set images. It includes the model builder, the
   preprocessing used by the server, a prediction helper and an `unlearn()`
   stub; running it saves the unchanged model as a baseline
   `submission.pt`.
· submission.py - the code to submit your model
